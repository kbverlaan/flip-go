# flip-go

Retro (Pokemon-stijl) OGS-client voor de Miyoo Flip.

- `python main.py` — spelen (Mac-test, 640x480)
- `python main.py --shot` — headless screenshots naar out/

Intern canvas 320x240, 2x geschaald = exact Flip-resolutie.
Besturing: pijltjes = D-pad, Enter/X = A, Backspace/Z = B, S = Start.

Status: titelscherm + bord-scene met mock-pot. Volgende: OGS OAuth + realtime socket.
